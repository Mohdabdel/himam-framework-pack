# 02 — الإطار المعرفي والمجالات التسعة

## 1. السلسلة المعرفية القياسية
Source → Evidence → Interpretation → Need → Current Performance/Baseline → Goal → Measure → Support → Age/Functional Outcome

هذه السلسلة تفصل صراحةً بين:
- معلومات المصدر (ماذا يقول المستند؟)
- الاستخراج (ما البند القابل للاقتباس؟)
- التفسير (ماذا يعني تربويًا؟)
- القرار (ماذا نستنتج؟)
كل انتقال بين مستويين يجب أن يكون قابلًا للتتبع ولا يُدمج مع سابقه.

## 2. المجالات التسعة

### D0 — قابلية المراجعة
هل تتوفر المدخلات الدنيا؟ هل الوثائق مقروءة؟ هل تخص المتعلم نفسه؟
غياب المدخل الحرج ⇒ الحالة "غير قابلة للمراجعة"، لا تُعامل كفشل.

### D1 — بنية الهدف
صياغة السلوك، الشروط، المعيار، الزمن، أداة القياس، الملاحظ.
يستند إلى إطار جودة الهدف بأبعاده الخمسة عشر (مواءمة الحاجة، خط الأساس،
تحديد السلوك، القياس، الملاحظة، الشروط، الإتقان، الزمن، القيمة التعليمية والوظيفية،
الجدوى، اتساق الدعم، الملاءمة الثقافية والسياقية، الانتقال عند الانطباق،
رصد التقدم، والمتطلبات التنظيمية عند تهيئتها).

### D2 — التخصيص وقاعدة الأدلة
هل يستند الهدف إلى حاجة موثقة في التقييم؟ هل خط الأساس محدد كميًا؟
هل الحاجة ذاتها مبررة بمصدر تقييمي متعدد لا برأي وحيد؟

### D3 — القيمة التعليمية/الوظيفية والجدوى
هل الهدف ذو قيمة توليدية أو وظيفية للمتعلم في سياقه؟
هل هو قابل للتحقيق في الأفق الزمني المحدد؟

### D4 — الدعم والتنفيذ
هل الدعم والتسهيلات مذكورة ومتسقة مع الهدف؟ هل هناك تعارض دعم؟

### D5 — الأسرة والمتعلم والسياق والإنصاف
هل تظهر أولوية الأسرة في هدف؟ هل صوت المتعلم مأخوذ عند مرحلته؟
هل الملاءمة الثقافية واللغوية والاجتماعية مراعاة؟

### D6 — المواءمة العمرية والمآلات
هل الهدف يتسق مع المآلات المتوقعة للمرحلة العمرية؟ (U/A/C/P — انظر الملف 06)
ملاحظة: العمر يحدد أولوية التفكير لا القدرة، ولا يولّد هدفًا بذاته.

### D7 — ترابط الأهداف
هل الأهداف مترابطة (builds_on / prepares_for / integrates_with / generalizes_to /
increases_independence_in) أم متكررة/متعارضة/معزولة؟

### D8 — جاهزية الرصد
هل مواصفة القياس تسمح فعلًا برصد التقدم؟ من يقيس؟ متى؟ بأي أداة؟

## 3. نموذج الصلاحية والجودة (متعدد المحاور)
- Evidence Validity
- Structural / Goal Quality
- Educational Coherence
- Implementation Readiness
- Outcome Accountability

لا يُدمج المحاور في رقم واحد. لا يُسمح لدرجة مرتفعة في محور بأن تُلغي فشلًا جوهريًا في آخر.

## 4. العلاقات بين الكيانات
Goal → Need — Goal → Baseline — Goal → Measure — Need → Evidence
كل علاقة مفقودة تُنشئ ملاحظة "غير متحقق" في المعيار المرتبط.

## 5. إطار مكونات الخطة (استرجاعي)
قائمة مصادر التقييم → توليف التقييم → الأداء الحالي/PLAAFP → الاحتياجات ذات الأولوية →
خط الأساس → الهدف → مواصفة القياس. المعمارية الشاملة للخدمات والتنفيذ خارج النطاق.

## 6. الممارسات عالية التأثير المرجعية
HLP 4, 5, 6, 11, 12, 13, 15 تُستخدم كإطار حوكمة داخلي.
البيانات الأولية الدقيقة لهذه الممارسات تُوسم Needs Verification في سجل المصادر.
